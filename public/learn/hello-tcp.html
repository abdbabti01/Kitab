Networking glossary
Socket
The app's way to ask the OS to connect, send, or read bytes.
Port
A number the OS uses to find the right network endpoint on a computer.
TCP segment
A TCP header with ports and sequence information, plus any data it carries.
IPv4 packet
An IP header with addresses wrapped around the segment.
Payload
What a header carries. An IPv4 packet carries the TCP segment. A data segment carries app bytes.
SYN and ACK
SYN starts a handshake. ACK acknowledges earlier bytes and names the next sequence number expected.
TTL
The packet's hop budget. A router subtracts one on the way through.
Next hop
The next device the packet is sent to on its way to the final IP address.
